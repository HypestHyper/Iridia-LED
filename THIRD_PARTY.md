Iridia talks to your hardware through [OpenRGB](https://openrgb.org/) (GPL-2.0), which you install
separately; no OpenRGB code is bundled. The Python libraries it installs from PyPI
(openrgb-python, Pillow, watchdog) keep their own licences.
